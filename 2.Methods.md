# 🧬 Automated Phylogenetic Pipeline for Gene Family Analysis

## 📖 Overview

This Python script automates the process of **retrieving proteomes from NCBI**, preparing them for analysis, and then **constructing phylogenetic trees** for multiple genes of interest.

It integrates several bioinformatics command-line tools (NCBI Datasets, MAFFT, HMMER, MMseqs2, IQ-TREE, etc.) to perform the following steps:

1. **Download proteomes and annotations** from NCBI or other sources.  
2. **Merge BLAST results** for selected genes.  
3. **Cluster and remove redundant sequences** using MMseqs2 and SeqKit.  
4. **Align sequences** using MAFFT and **trim** alignments with TrimAl or Gblocks.  
5. **Build HMM profiles** with HMMER and **search** against proteome databases.  
6. **Select top hits**, **re-align**, and **construct phylogenetic trees** using IQ-TREE.  
7. **Annotate trees** with full gene identifiers and species information.

This pipeline is designed for **comparative genomics** or **ortholog identification** across insects (or other taxa) and can be adapted for any set of target genes.

# 🧬 Phylogenomic Pipeline Documentation

## Overview
This pipeline automates the **retrieval, clustering, alignment, and phylogenetic analysis** of gene/protein sequences from multiple species.  
It integrates several bioinformatics command-line tools, performing the following major tasks:

1. Downloading genomes and proteomes from NCBI  
2. Merging and cleaning sequence data  
3. Removing redundancy and duplicates  
4. Multiple sequence alignment and trimming  
5. Hidden Markov Model (HMM) profile building and searching  
6. Extracting top hits and building phylogenetic trees  
7. Replacing identifiers for better tree labeling

---

## 1. `datasets` (NCBI Command-Line Tools)

**Used in:** `downloading_ncbi_data()`

**Example Command:**
```bash
datasets download genome accession GCF_000001405.39 --include gff3,protein,seq-report
```

**Purpose:**  
Downloads genome data from NCBI using an assembly accession.

**Flags & Values:**

| Flag | Description |
|------|--------------|
| `genome accession` | Specifies the type of dataset to download (genome data). |
| `<ACCESSION>` | NCBI assembly accession (e.g., GCF_XXXXXXX). |
| `--include gff3,protein,seq-report` | Includes:<br>• `gff3`: genome annotations<br>• `protein`: protein sequences<br>• `seq-report`: assembly metadata |

---

## 2. `mmseqs easy-cluster`

**Used in:** `removing_redundant_sequences()`

**Example Command:**
```bash
mmseqs easy-cluster input.fasta output tmp --min-seq-id 0.9
```

**Purpose:**  
Clusters similar sequences to remove redundancy and produce representative sequences.

**Flags & Values:**

| Flag | Description |
|------|--------------|
| `input.fasta` | Input protein FASTA file. |
| `output` | Output file prefix. |
| `tmp` | Temporary directory for intermediate files. |
| `--min-seq-id 0.9` | Minimum sequence identity (90%). Sequences ≥90% identical are clustered. |

**Output:**  
`output_rep_seq.fasta` — representative sequences of each cluster.

---

## 3. `seqkit rmdup`

**Used in:** `removing_duplicated_sequences()`

**Example Command:**
```bash
seqkit rmdup input.fasta -o output.fasta
```

**Purpose:**  
Removes duplicate sequences from a FASTA file.

**Flags & Values:**

| Flag | Description |
|------|--------------|
| `-o output.fasta` | Output file for deduplicated sequences. |

---

## 4. `mafft`

**Used in:** `align_sequences()`

**Example Command:**
```bash
mafft --auto input.fasta > output.fasta
```

**Purpose:**  
Performs multiple sequence alignment.

**Flags & Values:**

| Flag | Description |
|------|--------------|
| `--auto` | Automatically selects the most suitable alignment strategy. |
| `>` | Redirects output alignment to a file. |

---

## 5. `Gblocks`

**Used in:** `gblocks_trimming()`

**Example Command:**
```bash
Gblocks alignment.fasta -t=p -b5=h
```

**Purpose:**  
Trims poorly aligned or divergent regions from a multiple sequence alignment.

**Flags & Values:**

| Flag | Description |
|------|--------------|
| `-t=p` | Specifies that the input alignment is composed of protein sequences. |
| `-b5=h` | Allows up to half of sequences to have gaps in a block (relaxed trimming). |

**Output:**  
`alignment.fasta-gb` — trimmed alignment.

---

## 6. `trimal`

**Used in:** `trimal_trimming()`

**Example Command:**
```bash
trimal -in alignment.fasta -out alignment_trimmed.fasta -gt 0.7
```

**Purpose:**  
Trims columns from multiple sequence alignments based on gap threshold.

**Flags & Values:**

| Flag | Description |
|------|--------------|
| `-in` | Input alignment file. |
| `-out` | Output trimmed alignment file. |
| `-gt 0.7` | Keeps columns with ≤70% gaps (removes columns with >30% gaps). |

---

## 7. `hmmbuild` (HMMER)

**Used in:** `hmmer_profile()`

**Example Command:**
```bash
hmmbuild gene_name.hmm alignment_trimmed.fasta
```

**Purpose:**  
Builds a Hidden Markov Model (HMM) profile from a multiple sequence alignment.

**Inputs & Outputs:**

| Parameter | Description |
|------------|--------------|
| `alignment_trimmed.fasta` | Input multiple sequence alignment. |
| `gene_name.hmm` | Output HMM profile. |

---

## 8. `hmmsearch` (HMMER)

**Used in:** `hmmer_search()`

**Example Command:**
```bash
hmmsearch --tblout output_table.txt -E 1e-5 gene_name.hmm proteomes_database/all_proteomes.faa
```

**Purpose:**  
Searches an HMM profile against a protein sequence database to find homologs.

**Flags & Values:**

| Flag | Description |
|------|--------------|
| `--tblout output_table.txt` | Writes tabular output (summary hits). |
| `-E 1e-5` | E-value threshold (keeps hits with E ≤ 1×10⁻⁵). |
| `<profile.hmm>` | Input HMM profile. |
| `<database.faa>` | Protein FASTA database. |

---

## 9. `grep`, `awk`, and `seqtk`

**Used in:** The selection and extraction of the top 500 HMMER hits.

**Example Commands:**
```bash
grep -v '^#' output_table.txt | head -n 500 > output_500_hits.txt
grep -v '^#' output_500_hits.txt | awk '{print $1}' > ids.txt
seqtk subseq proteomes_database/all_proteomes.faa ids.txt > seqs_500.fasta
```

**Purpose:**  
Extracts the top 500 HMMER hits, retrieves sequence IDs, and extracts the corresponding sequences.

**Tools:**
| Tool | Description |
|------|--------------|
| `grep` | Filters out comment lines (those starting with `#`). |
| `head -n 500` | Keeps the top 500 hits. |
| `awk '{print $1}'` | Extracts the first column (sequence IDs). |
| `seqtk subseq` | Extracts sequences by ID from a FASTA database. |

---

## 10. `iqtree2`

**Used in:** `building_finalized_tree()`

**Example Command:**
```bash
iqtree2 -s alignment_trimmed.fasta -m TEST -bb 1000 -nt AUTO
```

**Purpose:**  
Builds a maximum likelihood phylogenetic tree and tests model selection automatically.

**Flags & Values:**

| Flag | Description |
|------|--------------|
| `-s` | Input alignment file. |
| `-m TEST` | Automatically tests multiple substitution models and selects the best. |
| `-bb 1000` | Performs 1000 ultrafast bootstrap replicates for branch support. |
| `-nt AUTO` | Automatically detects and uses available CPU cores. |

**Outputs:**  
Several files including:  
- `.treefile`: final phylogenetic tree  
- `.iqtree`: summary of the model and parameters  
- `.log`: log of execution

## 11. Custom Python Functions

| Function | Description |
|-----------|--------------|
| `shorting_seqs_names()` | Removes long descriptions from FASTA headers, keeping short IDs. |
| `modify_identifiers()` | Cleans and standardizes sequence headers for labeling. |
| `replace_identifiers_in_tree()` | Replaces short identifiers in tree files with full gene names/species. |

---

## 12. Example Workflow Summary

1. **Download Data:** `datasets download genome accession ...`  
2. **Cluster & Deduplicate:** `mmseqs easy-cluster`, `seqkit rmdup`  
3. **Align Sequences:** `mafft --auto`  
4. **Trim Alignments:** `trimal` or `Gblocks`  
5. **Build HMM:** `hmmbuild`  
6. **Search Database:** `hmmsearch`  
7. **Filter Top Hits:** `grep`, `awk`, `seqtk`  
8. **Align & Trim Again:** `mafft`, `trimal`  
9. **Build Tree:** `iqtree2`  
10. **Annotate Tree:** `modify_identifiers()` + `replace_identifiers_in_tree()`

## 15. Notes and Best Practices

- Run each major step in isolated directories to prevent file overwriting.  
- For large datasets, consider adjusting the MMseqs2 `--min-seq-id` and HMMER `-E` thresholds.  
- Always check intermediate alignments visually (e.g., with **AliView** or **Jalview**) before tree inference.  
- Keep a consistent naming scheme for gene directories (`gene_name/`) to simplify automation.
